How it works

Choices in. Website out.

Pick your package manager, industry, template style, sections, layouts, colors, fonts, CTAs and animation level.

2

Quick start

Download it. Run it. Ship a site.

Requires Go 1.22+ and Node.js. The CLI offers to install dependencies for you.

Download on GitHub ↗
# download and run the wizard
git clone https://github.com/therohantomar/go_with_theflow.git
cd go_with_theflow
go mod tidy
go run ./cmd/flow new

What you get

your-project/ ├─ src/ │ ├─ components/ sections, layout │ ├─ content/ one JSON per section │ ├─ assets/ empty photo folders │ └─ scripts/ animations ├─ flow.json your saved choices └─ package.json

FAQ

Questions, answered.

Do I need to know Go?

Only to build the CLI from source. Using it is just answering prompts. The site it creates is a regular Astro project you can edit with normal web tools.

Is AI involved?

No. Generation is deterministic: the same choices always produce the same site, built from a curated component library.

Can I change things after generating?

Yes. Edit the JSON in src/content, drop photos into src/assets, or change the Astro components directly.

Where can I host the result?

It builds to static files (npm run build → dist/), so Vercel, Netlify, Cloudflare Pages or any static host works.

Can I reopen a project and edit my choices?

Not yet. flow list and flow edit are on the roadmap. For now, edit the generated files or run the wizard again.

Do the contact and newsletter forms send anything?

Not yet. They are visual placeholders until you connect your own form endpoint.
